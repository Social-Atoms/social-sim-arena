# SCE Extension Adapter

This adapter reads the official SCE workbook by sheet name and complete column
headers. The first release candidate uses household spending growth, the
probability that stock prices rise, and the probability that unemployment rises.
The remaining six parsed indicators remain available for review but are not
registered as rounds.

The values are monthly US household-head measures. A question locks before the
named release day, freezes the workbook vintage, and resolves against the exact
release-day file. The measurement month is not the release date. The existing
SCE license record remains the rights basis. No task is activated here.
