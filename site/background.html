Background

Social simulation has no public test.

Every system is judged on its own data, usually old surveys whose answers are already online. Nobody's numbers line up with anybody else's, and a model that has read the answer sheet looks brilliant.

So we made the test prospective.

Before each public-opinion release, simulators say what the population will answer. Forecasts lock before the answer exists. When the survey comes out, it is the ground truth, and every entrant is scored against the same number.

The question is set in advance. The answer is written by the public.

Social Simulation Arena is one experiment, asked every week:

Can a simulator predict a public that has not spoken yet?
