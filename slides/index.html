The problem

Nobody can prove a simulated public works

Academia: two years, no verdict

  • Two years of LLM-simulated survey respondents, and the papers contradict each other: striking fidelity in one study, flattened subgroups in the next.
  • Every evaluation is retrospective, graded against old surveys (ANES, GSS) that may already sit in training data.
  • A retrospective test cannot tell social understanding apart from memorization, no matter how carefully it is run.

    • Industry: moved faster anyway

  • Simile raised $200M at $2B. Aaru, $88M at $1B.
  • Population simulations sold to EY, Accenture and live campaigns; even Gallup now works with Simile.
  • Their only validation: self-reported wins on test sets they pick themselves.
    • "AI polls are fake polls."  Nate Silver's site, this spring, banning them from its averages.
    The fix

    A referee no one can cheat

    We built one

  • A live benchmark for social simulation: models forecast the next public-opinion release before it is published.
  • Locked, hashed, scored in public. No human discretion between submission and score.
  • No one picks the test set, because the test set does not exist yet.

    • Why this works now

  • Established trackers publish on fixed calendars: every scheduled release is a free, contamination-proof exam.
  • Gallup ended its 88-year approval series in Feb 2026; the reference instruments are retreating.
  • The Nov 3 midterm is the natural finale: every forecast sealed before a single vote is counted.

    How

    Four trackers in, one submission, every board

    Entering a round

  • 1 · What the numbers mean. Each value is the number the tracker will publish: the Michigan index level, the % approving among YouGov's or Morning Consult's respondents, the pooled generic-ballot margin. Cell values are the published crosstab cells for that wave.
  • 2 · Where truth comes from. Michigan resolves on the official 10:00 ET release; YouGov on the wave's topline and crosstab workbook; Morning Consult on its weekly report; the generic ballot on a pre-registered multi-pollster pooled estimate.
  • 3 · How to submit. One JSON file per round, by pull request or the site's one-click template, any time before lock (release − 48 h). CI validates the schema and the deadline and prints your sha256. Late means void, enforced in code.
  • 4 · The format.
    • forecasts/<round>/<you>.json
{ "topline": { "mean": 39.0, "sd": 2.0 },
  "cells": {
    "Democrat":   { "mean": 5,  "sd": 1.5 },
    "Republican": { "mean": 87, "sd": 2.0 },
    "Under 30":   { "mean": 34, "sd": 3.0 },
    ...16 cells: party, age, race,
       gender, education } }
  • A distribution, not a point: mean and sd per value, or quantiles. Confidence is scored, so bluffing costs.
