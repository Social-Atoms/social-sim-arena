The problem

Social simulation has a trust problem

The state of play

  • "AI polls are fake polls." Silver Bulletin, banning them from its averages, Apr 2026.
  • Simile ($2B) and Aaru ($1B) sell simulated populations to EY, Accenture and live campaigns (even Gallup partners with Simile), validated only by wins they grade themselves.
  • Scholars call the samples caricatures of the groups they claim to speak for (CoMPosT EMNLP 2023); AAPOR and ESOMAR are drafting rules for AI respondents.

    • The verdict is split

    FOR

  • Generative Agent Simulations of 1,000 People 2024: interview-built agents hit 85% of people’s own GSS consistency.
  • Out of One, Many Political Analysis 2023: GPT-3 mirrors how real subgroups answer.
  • The market believes: Aaru sells agent “polls” of census-programmed chatbots for live races (Semafor); Gallup itself now validates Simile on its national panel (Gallup, May 2026).

    • AGAINST

  • Synthetic Replacements? Political Analysis 2024: too uniform to stand in for people; NMI 2025 sees identity groups flattened.
  • The Illusion of Artificial Inclusion CHI 2024: replacement defeats why research asks humans at all.
  • The press counts the misses: on election eve 2024 Aaru had Harris ahead in Michigan, Nevada, Pennsylvania and Wisconsin, all four lost; Silver Bulletin bans AI polls outright (“AI polls are fake polls,” Apr 2026).

    • Both sides grade the past. ANES and GSS sit in training data, so memory can pass for understanding.

    So we asked: what would an uncheatable, third-party referee look like? A live benchmark against the real future. Forecast the next release before it is published: locked, hashed, scored in public. No one picks the test set, because the test set does not exist yet.

    Every earlier test grades the past (OpinionQA, SimBench, SocietyBench, ANES/GSS replays); this one is graded by answers that do not exist yet.

    The idea

    A live benchmark, graded by the real future

    Left of the green line, every number is already published. Entries are hashed and locked 48 hours before each release; past the line the answer does not exist yet, and the release itself grades everyone in public.

    How

    A live bench built on four recurring data sources

    Each round: forecast the tracker’s next release. Entries lock 48 hours before the number comes out; the release itself grades everyone; then the next round starts.

    Entering a round

  • How to submit. One JSON file per round, by pull request or the site’s one-click template, any time before lock (release − 48 h). CI validates the schema and the deadline and prints your sha256. Late means void, enforced in code.
  • The format. A distribution, not a point: mean and sd per value, or quantiles. Confidence is scored, so bluffing costs. One file covers the topline and all 16 cells.
    • forecasts/<round>/<you>.json
{ "topline": { "mean": 39.0, "sd": 2.0 },
  "cells": {
    "Democrat":   { "mean": 5,  "sd": 1.5 },
    "Republican": { "mean": 87, "sd": 2.0 },
    "Under 30":   { "mean": 34, "sd": 3.0 },
    ...16 cells: party, age, race,
       gender, education } }
